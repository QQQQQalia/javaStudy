# 用户中心前端（Vue 3 + Vite）

基于后端接口实现的登录页 / 注册页 / 用户中心，另外保留了一个接口联调自检台。

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/login` | 登录页 | 用户名 + 密码 + 验证码；登录成功保存 token，失败自动换一张验证码 |
| `/register` | 注册页 | 注册成功后跳到登录页，并自动填好用户名 |
| `/home` | 用户中心 | 账号信息、修改密码、注销账号；未登录会被路由守卫挡回登录页 |
| `/dev` | 接口自检台 | 逐个接口手工调用，带请求记录面板 |

登录态存在 `localStorage`；接口返回 401（token 过期或伪造）会自动清登录态并跳回登录页。

## 启动

先启动后端（默认 3000 端口）：

```bash
mvn spring-boot:run
```

再启动前端：

```bash
cd web
npm install
npm run dev
```

浏览器打开 <http://localhost:5173>，未登录会自动跳到登录页。

## 两个必须注意的点

- 前端端口必须是 **5173**：后端 `GlobalMvcConfig` 里 CORS 只放行了 `http://localhost:5173`，
  换端口或者用 `127.0.0.1` 打开都会被浏览器拦掉。
- 所有请求都带 `credentials: 'include'`：验证码存在 session 里，靠 `JSESSIONID` 这个
  cookie 串起来。登录必须和获取验证码用同一个浏览器会话。

后端地址默认 `http://localhost:3000`，需要改的话在 `web/.env.local` 里写：

```
VITE_API_BASE=http://localhost:3000
```

## 手工验证顺序

1. 直接访问 `/home`，应被守卫挡回登录页。
2. 去注册页建一个账号，成功后回到登录页并自动填好用户名。
3. 故意填错验证码登录，页面提示「验证码错误」并自动换一张。
4. 填对验证码登录，进入用户中心，顶部显示用户名。
5. 在用户中心修改密码，退出登录后用新密码重新登录。
6. 注销账号后，再用同一账号登录会提示「用户不存在」。
7. 打开 `/dev` 逐个接口手工验证，其中「不带 token」应返回 401。

## 自动验证

不开浏览器，直接跑后端全链路自检（含验证码识别、跨域预检）：

```bash
pip install ddddocr
python scripts/api_check.py
```
